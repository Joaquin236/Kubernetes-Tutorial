## 103.1º La herramienta Kustomize permite personalizar algunos aspectos del despliegue de Kubernetes. En un desliegue, hay tres directiorios con un fichero cada uno. ["dev:nginx-depl.yaml","stg:nginx-delp.yaml","prod:nginx-delp.yaml"]. Las diferencias entre los ficheros son: el número de replicas que despliegan los ficheros. Para aplicar este formato de despliegue establecemos el nombre del directorio kubectl apply -f dev/
