## 93.1º ETCD es un distribuidor reliable con lenguaje ["Clave","Valor"], de uso simple, rápido y seguro. El contenido viene establecido a través de tablas. Como es JSON o YAML. 

## 93.2º ETCD tiene el objetivo de garantizar la integridad de las Entradas y Salidas del sistema de almacenamiento. El programador lider se encarga de las acciones de los comandos. Para elegir quien realizará las acciones está el cálculo --> Quorum=3/2+1=2.5~=2 --> Si lleva decimal solo se valida el número entero.
